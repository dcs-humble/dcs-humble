## 添加新学期或新课程

1. 确认资料所属学期和课程名称，不根据笔记日期推断教学学期。
2. 在本地展开资料，按课件、学习笔记、习题与答案、实验资料、课程设计、复习考试、参考资料分类。
3. 相同内容的文件保留一份；同名但内容不同的版本分别保留，并写清版本区别。
4. 将本课程完整资料打成 ZIP，附文件清单和 SHA256 校验值。
5. 把课程 ZIP 放到仓库的 Releases，在 courses 目录新增本课程的说明页。
6. 在课程总目录增加入口，更新主页的课程数量和实际覆盖范围。

## 命名约定

- 课程页面：学期代码-课程英文标识.md，例如现有 y2s2-materials-mechanics-2.md。
- 课程下载包：使用与课程页面相同的标识，扩展名改成 .zip。
- 中文课程名称显示在页面标题和目录表中，方便浏览和搜索。
- y2s2 表示大二下；y3s1 表示大三上。学期代码用于整理资料，不表示已覆盖完整培养方案。

## 更新已有课程

资料有变化时，保留旧版本下载包，建立新的发布版本，并让课程说明页指向实际的新包。同步更新文件清单、大小、校验值和更新说明，避免下载内容与页面描述不一致。

## 大文件存放

完整课程大文件存放在 Releases；Git 仓库保留课程索引、说明、图片和工具代码。普通 Git 仓库会阻止超过 100 MiB 的文件，网页直接上传文件的限制是 25 MiB。

参考：[GitHub 大文件说明](https://docs.github.com/en/repositories/working-with-files/managing-large-files/about-large-files-on-github)。

## 待核对材料

本次资料中的成绩、个人标识、个人设计成品和视频等已单独保留在本地待核对清单。后续补充资料时，也先区分通用课程资料与个人提交材料，再决定具体收录范围。

## 自研工具

每个工具保留独立说明，写清解决的问题、运行环境、安装步骤、真实使用示例和当前状态。工具尚未提供时，目录维持待补充状态即可。
