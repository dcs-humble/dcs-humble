# 资料维护指南

[← 首页](../README.md) · [补充资料流程](../CONTRIBUTING.md)

## 目录约定

资料放在 `课程资料/学期/课程名/分类/文件`。已有分类包括课件、学习笔记、习题与答案、复习考试、实验资料、课程设计和参考资料；按实际内容使用，无需创建空分类。

学期目录保留课程导航。具体课程及分类目录直接显示文件，不再创建重复的 README 页面。

## 文件和索引

- 新文件尽量保留清晰的中文名称；有多个版本时注明年份或版本，避免覆盖内容不同的同名文件。
- 相同内容的副本不重复收录；不根据文件修改日期推断学期。
- 更新学期导航、[文件索引](FILES.md)和课程 CSV 清单；数量以实际文件为准。
- 课程 ZIP 是独立发布的备份。更新目录文件后，不会自动同步到 ZIP；发布新备份时应同时更新下载链接与校验信息。

## 大 PDF

单文件需低于 GitHub 的大小限制；本仓库分册尽量控制在 95 MiB 以内。超过时按页拆分，注明原文件页序，核对总页数与渲染效果，并在本地保留原件。不要通过降低清晰度替代分册。

[已有 PDF 分册记录](PDF-PARTS.md)

## 发布前核对

确认文件能打开、课程分类正确、导航链接有效。含姓名学号、成绩或其他个人信息的材料先留在本地核对；上传资料时说明来源与可分享范围，不擅自替第三方材料附加开源许可。
