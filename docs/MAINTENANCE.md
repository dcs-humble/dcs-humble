## 新增课程

在“课程资料/学期/课程名”下创建目录，再按实际需要建立课件、学习笔记、习题与答案、实验资料、课程设计、复习考试或参考资料子目录。

将实际文件放进对应目录，并更新课程 README、学期 README 和课程总目录。文件较多时可附 CSV 索引。

## 更新文件

内容相同的副本不重复上传；同名但内容不同的版本分别保留，并注明区别。

## 超大 PDF

单个 PDF 超过 GitHub 100 MiB 限制时，按原文页序拆分成上、下部分；若仍超限则继续细分。每份建议控制在95 MiB以内，核对原文页码、总页数与渲染效果，并保留原 PDF 备份。不要通过降低清晰度来代替按页拆分。

## 内容边界

按实际来源标注学期，不根据文件日期推断学年。个人成绩、个人标识等材料先保留在本地待核对。工具按真实功能和使用方式填写，未提供的项目保持待补充。
