# 使用指南

[← 返回主页](../README.md) · [课程总目录](../courses/README.md) · [课程资料下载区](https://github.com/dcs-humble/dcs-humble/releases/tag/courses-2026-11-04)

## 找到需要的课程

在课程总目录按“大二下”或“大三上”选择课程。每门课程页面提供分类统计、文件清单和完整资料下载入口。

## 下载课程资料

1. 点击课程页面的“下载本课程 ZIP”，或在课程总目录中点击“下载 ZIP”。
2. 下载后解压，按课件、习题、实验、复习等分类查找。
3. 下载包内有 README.md 和 MANIFEST.csv，后者列出文件大小与 SHA256 校验值。
4. 不同课程分别打包，只需下载自己需要的课程。

仓库主页的 Code → Download ZIP 下载的是目录、说明和工具等仓库内容；完整课程大文件需要通过课程下载区获取。

## 使用自研工具

进入 [工具实验室](../tools/README.md)，阅读具体工具的环境、安装与使用示例。当前工具仍待补充，未添加虚构项目。

## 反馈问题

在本仓库或对应工具仓库的 Issues 中提供课程或工具名称、文件位置、具体问题。工具故障再补充操作步骤和实际结果。

## 维护课程索引

新增课程可以从 [课程模板](../templates/COURSE.md) 开始。上传资料包后，在课程页填入实际下载链接，同时更新课程总目录和文件清单。

资料可能来自不同教学年份，请结合当前教师要求核对。含个人标识、成绩、视频或个人设计成品的待核对材料暂未公开。

## 后续维护

新增学期、更新课程下载包或添加工具，请参考 [维护指南](MAINTENANCE.md)。
