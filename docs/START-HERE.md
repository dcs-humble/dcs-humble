# 找资料与下载

[← 首页](../README.md) · [课程目录](../课程资料/)

## 找到需要的内容

- **平时学习**：选课程，再打开「课件」「学习笔记」等分类。
- **考前复习**：首页点课程旁的「复习」，直接进入复习文件夹。
- **下载整门课程**：进入学期目录，点对应课程的 **ZIP**。

课程和分类里直接显示实际文件；用 GitHub 顶部的路径导航可返回上一层。

## 下载单个文件

打开文件，点击 **Download raw file（下载图标）**。部分文件页面显示 **Raw**，可打开原文件后保存。无法在线预览的大 PDF、Word、PPT，也可以下载后用本地软件打开。

## PDF 分册怎么读

地质和土力学复习各分为上下两份；钢结构复习分为上-1、上-2、下-1、下-2。按这个顺序阅读，清晰度与原件一致。

## 只下载自己需要的课程

学期目录提供每门课程的 ZIP 链接，包含拆分前的大 PDF。整个仓库体积较大，下载单个文件或课程整包更方便。
