## 浏览课程资料

进入根目录的“课程资料”，依次选择学期、课程和分类。课件、习题、实验和复习资料都作为实际文件存放。

课程与分类目录的 README 提供文件索引。点击文件名即可打开；GitHub 支持的文档可在线预览，其他文件可从文件页面单独下载。

## 下载文件

打开文件页面，使用 Download raw file 或下载按钮。无需先下载课程 ZIP。

## 上、下部分 PDF

三份超大 PDF 已拆成八份，文件名标明上、下或分部序号，课程索引注明原文页码。按顺序阅读即可，页面未重新采样。

## 整包备份

每门课程页面仍有原始课程 ZIP 下载，包含拆分前的 PDF。Code → Download ZIP 则下载当前仓库内全部实际资料，体积较大。
