## 建议的整理方式

每门课程建立一个文件夹，内部按实际需要放置：
- 课程说明与知识框架
- 学习笔记
- 实验、练习与代码
- 复习提纲
- 参考资料链接

下列是命名示例，不代表已经收录这些课程：

```text
courses/
└── 2026-2027/
    └── semester-1/
        └── course-name/
            ├── README.md
            ├── notes/
            ├── labs/
            └── review/
```

将 [课程模板](../templates/COURSE.md) 复制为具体课程文件夹中的 README.md，再把课程链接填入上面的索引。文件夹仅在实际添加文件时创建即可。
