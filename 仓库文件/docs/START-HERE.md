# 使用指南

[← 返回主页](../README.md)

## 我想找课程资料

打开 [课程总目录](../courses/README.md)，根据学年和学期查找课程。每门课程的 README 会说明资料范围、文件位置和整理进度。当前仍在搭建目录，具体课程将逐步添加。

## 我想使用某个工具

打开 [自研工具目录](../tools/README.md)，进入工具说明，依次阅读支持环境、安装方法和使用示例。目录也可能链接到独立项目仓库。

## 下载单个文件

在 GitHub 中打开对应文件，使用文件页面提供的下载按钮；文本文件也可以打开 Raw 原始内容后保存。具体按钮会因文件类型而不同。

## 下载整个仓库

进入仓库主页，选择 Code → Download ZIP，下载后解压。这样可以获得当时分支上的全部文件。

## 反馈内容问题

请提供：
- 课程名称或工具名称
- 对应文件链接
- 问题描述；如果是工具问题，再附操作步骤和实际结果

可以通过本仓库的 Issues 反馈（需仓库开启 Issues），也可在对应工具仓库反馈。

## 我是仓库维护者，怎样新增内容？

**添加课程：** 从 [课程模板](../templates/COURSE.md) 开始，放入 courses 下的具体课程文件夹，再更新课程总目录。

**添加工具：** 从 [工具模板](../templates/TOOL.md) 开始，补全介绍与操作步骤，再更新工具总目录。如果工具已有独立仓库，直接在目录中链接过去。

**记录更新：** 在相关课程或工具说明中写清变更内容；工具版本变化时，可使用 [版本记录模板](../templates/CHANGELOG.md)。
