## 每个工具建议包含

1. 功能介绍与适用场景
2. 支持环境与安装步骤
3. 能直接照着操作的使用示例
4. 截图、输出示例或演示
5. 常见问题与版本记录

## 存放方式

- 小型脚本：放入本目录的独立子文件夹，并提供自己的 README。
- 独立项目：保留原仓库，在上表添加它的仓库链接。
- 已发布的程序：在工具说明中提供实际发布页面和对应版本。

工具状态统一使用：构思中 / 开发中 / 测试中 / 可用 / 暂停维护。请按实际情况填写。
